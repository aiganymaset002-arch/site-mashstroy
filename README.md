# 🌐 My First simple workable  Website After Harvard CS50
This is a small website I created after completing **Harvard CS50** to practice and test my basic knowledge of **simple workable HTML and web development**.
The project was mainly a hands-on experiment: I wanted to take what I had learned in CS50 and build something independently, while also exploring how **AI tools such as Stitch AI** can help with website ideas and design.
I originally created the concept and code as a quick project in my notebook and then turned it into a working website. After finishing it, I deployed the site using **Netlify**.
### 🛠️ What I used
* HTML
* Basic web development
* AI-assisted design/experimentation
* Stitch AI
* Netlify
### 🎯 Why I made it
This wasn't intended to be a complex production project. It was a **practice project after CS50** — a way to check whether I could take my basic knowledge and actually build and deploy something on my own.
It was one of my first steps from **learning code → building something → putting it online**.
